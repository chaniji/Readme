# Go (Golang)

Go is a statically typed, compiled programming language designed at Google. It is syntactically similar to C, but with memory safety, garbage collection, structural typing, and CSP-style concurrency.

> [!info] Design Goals
> Simplicity, efficiency, and reliability. Built for modern multicore and networked systems.

## Key Features
- **Goroutines:** Lightweight threads managed by the Go runtime for high-performance concurrency.
- **Fast Compilation:** Designed for quick build cycles.
- **Static Typing:** Combines safety with the speed of compiled code.
- **Simple Syntax:** Minimizes cognitive load.

## Usage in Projects
- Used for high-concurrency services like the Notification Service in the [[Articles/ERP-System|ERP Project]].
