HOW TO USE THESE EXAMPLES

1. Choose an example that matches your use case
2. Copy the entire prompt (from @springboot-project-creator to the end)
3. Paste it into Claude
4. Let the skill generate your project scaffold
5. Extract the files
6. Run: mvn clean install
7. Start implementing your domain logic

================================================================================
CUSTOMIZATION TIPS
================================================================================

Service Name Best Practices:
  ✓ Use kebab-case: my-service, user-service, order-processor
  ✓ Be descriptive: what does it do?
  ✓ Avoid generic names: not just "service"
  Examples: payment-service, inventory-manager, notification-hub

Package Best Practices:
  ✓ Use domain-based packages: com.domain.subdomain
  ✓ Follow Java conventions: lowercase, no hyphens
  ✓ Be specific: com.acme.billing not just com.acme
  Examples: com.company.users, org.banking.transactions

Port Selection:
  ✓ Use ports 8080-8099 for development
  ✓ Avoid well-known ports (80, 443, 3306, 5432)
  ✓ Document port assignments for your team
  Common pattern: 8080 (primary), 8081 (secondary), etc.

Database Naming:
  ✓ Use snake_case: my_database, users_db
  ✓ Match service name: payment_service → payment_service_db
  ✓ If not specified: auto-generated from service name

TROUBLESHOOTING
================================================================================

Q: What if I forget to specify the port?
A: Default port 8080 will be used

Q: What if I forget the database name?
A: Auto-generated from service name (my-service → my_service_db)

Q: Can I change these after generation?
A: Yes! Edit pom.xml and application.yml

Q: Do I need all the information?
A: Minimum required:
   - Service name
   - Base package
   
   Optional:
   - Port (defaults to 8080)
   - Database name (auto-generated)
